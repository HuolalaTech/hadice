# 连接设备

## 功能介绍

Hadice 通过 USB 或无线调试连接 **HarmonyOS Next** 与 **Android** 设备。连接成功并授权后，即可进入设备总览、性能监控、应用管理、网络抓包等功能页。

## 前提条件

- 已安装 Hadice 桌面端（macOS / Windows）
- 已准备支持 USB 调试的数据线（USB 连接方式），或手机与电脑处于同一局域网（无线调试方式）
- 设备已开启开发者模式与 USB 调试

## 开启开发者模式

### 鸿蒙手机

1. 进入「设置 > 关于本机 > 软件版本」，连续点击 7 次「软件版本」
2. 返回「设置 > 系统 > 开发者选项」，启用「开发者选项」和「USB 调试」

### 安卓手机

1. 进入「设置 > 关于手机」，连续点击「版本号」7 次
2. 返回「设置 > 开发者选项」，启用「USB 调试」

## USB 连接

1. 将手机通过 USB 数据线连接到电脑
2. 在 Hadice 右上角点击「刷新」图标
3. 在手机上点击「允许此电脑调试设备」
4. 设备出现在设备列表中后即可使用

## 无线调试

1. 在安卓手机的「开发者选项」中打开「无线调试」，并在弹窗中确认
2. 无线调试页面会显示「IP 地址和端口」（注意使用英文冒号，例如 `192.168.1.10:5555`）
3. 在 Hadice 的无线调试对话框中，将 IP 地址和端口填入输入框，点击「连接」
4. 连接命令完成后，点击「刷新」设备列表确认连接状态

## 连接诊断

如果刷新后设备未出现或连接异常，可运行「连接诊断」查看排查信息，按提示检查数据线、开发者选项、USB 调试授权等。

## FAQ

<details>
<summary>设备信息显示不完整？</summary>

请确保设备已正确连接并授权调试。尝试拔插 USB 线并重新授权，然后点击「刷新」。
</details>

<details>
<summary>无线调试无法连接？</summary>

确认手机与电脑处于同一局域网，且「IP 地址和端口」中的冒号为英文冒号。连接命令完成后需要刷新设备列表确认状态。
</details>
