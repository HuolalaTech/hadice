# 系统信息

![系统信息界面](/screenshots/10-infos.png)

## 功能介绍

系统信息页面展示设备的全部系统属性（类似安卓 Build 类信息与鸿蒙系统参数），包括品牌、型号、CPU 架构、屏幕分辨率、系统版本、编译信息等，支持按属性名或值搜索、高亮与一键复制。

## 前提条件

- 已连接设备并授权调试
- 鸿蒙与安卓设备均支持

## 界面布局

- **标题栏**：标题（含窗口/帮助按钮）、刷新按钮
- **搜索栏**：搜索框、属性计数（当前数量 / 总数量）
- **属性表格**：属性名、值、复制按钮

## 界面与按钮说明

### 属性列表

页面展示设备的所有系统属性，按属性名排序。每行展示属性名与属性值（较长内容自动省略，悬停可查看完整值）。

### 搜索过滤

- 搜索框输入关键词会同时匹配 **属性名或值**
- 匹配内容会以黄色高亮显示
- 搜索框下方实时显示「当前数量 / 总数量」，未匹配时提示「未找到匹配的属性」

### 刷新

右上角「刷新」按钮重新读取设备系统属性。

### 复制

每行属性右侧的复制按钮可复制该行内容到剪贴板，复制成功显示勾选状态。

## 使用场景

- 确认设备型号、系统版本、CPU 架构等配置信息
- 把特定属性值复制给开发或测试同事
- 对比不同设备的系统参数差异

## FAQ

<details>
<summary>系统信息与设备总览有什么区别？</summary>

系统信息展示设备全部系统属性（长列表，可搜索），设备总览只展示电池、CPU、内存、存储等精选摘要。
</details>

<details>
<summary>复制按钮复制的是什么内容？</summary>

点击行内复制按钮会把该行属性名与属性值一起复制到剪贴板。
</details>
