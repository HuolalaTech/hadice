# 终端命令

![终端命令界面](/screenshots/11-terms.png)

## 功能介绍

终端命令页面提供一个基于 node-pty 与 xterm.js 的本地 shell 终端，可以直接执行本机命令（包括 hdc / adb 工具命令），并支持把常用命令保存为快捷命令一键执行，适合高级调试场景。

## 前提条件

- 本地终端不依赖设备连接，可直接使用
- 需要操作设备时，请先连接设备并授权调试，再在终端中执行对应的 hdc / adb 命令

## 界面布局

- **标题栏**：标题（含窗口/帮助按钮）、重启终端、快捷命令
- **终端区域**：基于 xterm.js 的交互式终端

## 界面与按钮说明

### 交互式终端

- 页面提供完整的终端环境（node-pty + xterm.js），支持直接输入与执行命令
- 终端窗口大小自适应，支持 Unicode 与超链接识别
- 可直接运行本机命令，连接设备后可执行 hdc / adb 等设备命令

### 重启终端

- 「重启终端」按钮结束当前 shell 进程并重新启动，同时清空终端内容
- 终端无响应或执行状态异常时可使用

### 快捷命令

- 「快捷命令」菜单展示 **内置命令** 与 **自定义命令**
- 点击命令会把命令输入到终端中（光标停在命令末尾，按回车即可执行）
- 通过「添加快捷命令」对话框可新增自定义命令
- 自定义命令可删除，内置命令不可删除

## 使用场景

- 在电脑上直接执行 hdc / adb 命令操作设备
- 把高频命令（如抓包、查进程、清缓存）存为快捷命令
- 需要交互式 shell 时替代外部终端

## FAQ

<details>
<summary>终端无响应怎么办？</summary>

尝试断开并重新连接设备，然后重新打开终端。如果问题持续，可以在快捷操作中点击「重启终端」。
</details>

<details>
<summary>执行某些命令提示权限不足？</summary>

部分系统命令需要 root 权限才能执行，普通调试模式下无法使用这些命令。
</details>

<details>
<summary>快捷命令只能保存一次吗？</summary>

自定义命令会保存到本机，可随时新增或删除；内置命令始终可用。
</details>
