## 功能指南

| 章节 | 说明 |
| --- | --- |
| [设备总览](./device-overview) | 电池、CPU、内存、存储与系统信息 |

| [应用管理](./app-manager) | 启动、停止、卸载与清理应用数据 |

| [投屏截屏](./screenshot) | 实时镜像、截图、录屏与历史管理 |
| [文件传输](./file-transfer) | 设备与电脑双向互传，支持批量队列 |
| [系统日志](./system-logs) | hilog / logcat 实时查看、过滤与保存 |
| [网络抓包](./network-capture/) | 鸿蒙抓包（Sophon / HiProfiler） |
| [安卓抓包](./network-capture/android) | JVMTI Agent 与 WebView CDP，支持 Mock |
| [系统信息](./system-info) | 浏览并搜索设备系统属性 |
| [终端命令](./hdc-shell) | 本地终端与快捷命令 |
| [AI 自动化](./ai-automation) | 基于视觉与指令的设备自动化操作 |
