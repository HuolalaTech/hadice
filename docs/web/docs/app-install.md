# 应用安装

![应用安装界面](/screenshots/05-install.png)

## 功能介绍

应用安装页面支持把 APK（安卓）或 HAP（鸿蒙）安装包快速安装到设备上，支持文件对话框选择与拖拽两种方式。选择安装包后会自动解析并展示应用信息，确认无误后一键安装。

## 前提条件

- 已连接设备并授权调试
- 安卓设备：`.apk` 安装包
- 鸿蒙设备：`.hap` 等安装包（支持 `.hap`、`.hsp`、`.har`、`.zip`、`.gz`、`.7z`、`.tar` 等格式）
- 鸿蒙系统仅支持安装经过华为签名认证的安装包，且设备 UDID 需要在开发者证书中注册

## 界面布局

- **标题栏**：标题（含窗口/帮助按钮）、「选择安装包」「安装应用」按钮
- **文件信息区**：文件路径、大小、修改时间、解压路径（HAP）
- **应用信息区**：应用图标、名称、版本号（versionName / versionCode）

## 界面与按钮说明

### 选择安装包

点击「选择安装包」按钮，在文件对话框中选择要安装的 APK / HAP 文件。选择后页面自动解析并展示：

- 文件路径
- 文件大小与修改时间
- 鸿蒙安装包的解压路径（点击解压路径可打开所在文件夹）
- 应用图标、应用名、版本号

解析过程中显示「正在解析安装包信息...」，解析失败会在文件信息区以红色提示错误原因。

### 拖拽安装

将安装包文件直接拖放到页面安装区域，即可自动读取并展示安装包信息（Wails 文件拖放事件）。

### 安装应用

- 文件信息展示后点击「安装应用」执行安装
- 安装过程中按钮显示「正在安装...」并禁用
- 安装完成前请保持页面开启；安装完成后可切换到其他页面

### 覆盖安装

如果设备上已存在同包名的应用，会进行覆盖安装，但签名必须一致。

## 使用场景

- 测试包频繁迭代时快速安装最新版本
- 使用拖拽方式批量安装多个 APK
- 安装前先查看应用版本与图标，避免装错包

## FAQ

<details>
<summary>鸿蒙安装包安装失败怎么办？</summary>

鸿蒙系统仅支持安装经过华为签名认证的应用安装包，且设备 UDID 需要在开发者证书中注册。如需安装自定义应用，请联系鸿蒙 APP 开发者获取签名服务。
</details>

<details>
<summary>支持后台安装吗？</summary>

安装过程需要保持页面开启，安装完成后可以切换到其他页面。
</details>

<details>
<summary>可以覆盖安装吗？</summary>

可以。如果设备上已存在同包名的应用，会进行覆盖安装，但签名必须一致。
</details>

<details>
<summary>拖拽安装没有反应？</summary>

请确认拖放的是受支持的安装包格式（安卓 `.apk`；鸿蒙 `.hap`、`.hsp`、`.har`、`.zip`、`.gz`、`.7z`、`.tar` 等），也可以改用「选择安装包」按钮。
</details>
