# Support

Hadice is an open-source desktop debugging toolkit from **货拉拉**.

## Where to get help

| Need | Channel |
|------|---------|
| Bug report / feature request | [GitHub Issues](https://github.com/HuolalaTech/hadice/issues) |
| Usage questions / discussion | [GitHub Discussions](https://github.com/HuolalaTech/hadice/discussions) (if enabled) or Issues |
| Security vulnerability | [SECURITY.md](./SECURITY.md) only |
| In-app help | Help dialog inside the application |

## Documentation

- Chinese: [README.md](./README.md)
- English: [README_EN.md](./README_EN.md)
- Agent / contributor overview: [AGENTS.md](./AGENTS.md)

## What we do not provide

- Guaranteed SLA / commercial support via GitHub
- Debugging of unrelated third-party apps beyond what Hadice already exposes
